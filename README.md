## Sobre o Projeto

**JOVI LensAI** é uma landing page acadêmica desenvolvida para a Sprint 2 da disciplina de Web Development da FIAP. O projeto apresenta um produto fictício: uma câmera com IA contextual voltada para estudantes, capaz de identificar o ambiente de aprendizagem e adaptar o suporte visual em tempo real.

A página foi construída inteiramente com HTML, CSS e JavaScript puros — sem frameworks —, com foco em boas práticas de estrutura semântica, design responsivo e interatividade via DOM.

**Credenciais demo:** `ana@fiap.com` / `123456`

---

## Objetivo de Aprendizado

Esta sprint teve como foco a consolidação dos seguintes conceitos:

**HTML5**
- Estruturação semântica de páginas com tags como `<section>`, `<nav>`, `<header>`, `<footer>` e `<article>`
- Formulários com atributos de validação nativa

**CSS3**
- Variáveis CSS (`custom properties`) para gerenciamento de temas claro/escuro
- Layout moderno com **CSS Grid** e **Flexbox**
- Responsividade com **media queries**
- Animações e transições com `@keyframes` e `transition`

**JavaScript**
- Manipulação do **DOM** — seleção, criação e remoção de elementos
- Persistência de dados com **`localStorage`**
- Validação de formulários via JS
- Lógica de slideshow com `setInterval` e controles de navegação

## Funcionalidades

- **Autenticação simulada** — telas de login e cadastro com validação de campos e persistência via `localStorage`
- **Navbar responsiva** — menu hamburguer para mobile e alternância de tema claro/escuro
- **Hero animado** — seção principal com mockup da câmera e animações CSS
- **Galeria slideshow** — carrossel com reprodução automática e controles manuais
- **Cards de funcionalidades** — apresentação interativa dos recursos do produto
- **Comparação antes/depois** — seção "IA em Ação" com slider de imagens reais
- **Formulário de contato** — validação de campos com feedback visual em tempo real
