# JOVI LensAI — Sprint 2 Web Development

Projeto acadêmico FIAP — aplicação web de landing page para o produto **JOVI LensAI**, uma câmera com IA contextual para estudantes.

## Tecnologias

- HTML5
- CSS3 (variáveis, grid, flexbox, responsividade)
- JavaScript (DOM, localStorage, validações)

## Funcionalidades

- Tela de login e cadastro com validação e persistência via localStorage
- Navbar responsiva com hamburger menu e alternância de tema dark/light
- Hero section com mockup de câmera animado
- Galeria slideshow com auto-play e controles
- Seção de funcionalidades com cards interativos
- Comparação antes/depois com imagens reais (IA em Ação)
- Formulário de contato com validação

## Como rodar

Abra o arquivo `index.html` diretamente no navegador.
